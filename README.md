# 3-Step 漢方

臨床研修 指導ガイドライン（2024年度版）～経験すべき29症候で出会う頻用漢方処方～

医学生・初期研修医が、症候ごとに漢方薬を「4つ想起 → 2つに絞る → 1つに決める → 確認の問い」の3段階で選んで学ぶ、ブラウザ用の学習アプリです。

## 使い方

公開ページ（GitHub Pages）を開くだけで、PC・スマホのブラウザで使えます。インストールやログインは不要です。

- 症候（または症状）を選んで、症例を始めます。
- 最後まで「×」がなければ合格です。合格した症例は「経験したい症状・症候」に記録されます。
- 記録はお使いのブラウザにだけ保存されます（localStorage）。サーバーには送信されません。
- 「記録をリセット」で、保存した記録を消せます。

## 内容と根拠

- 症候は、臨床研修の「経験すべき症候」（29症候）に沿っています。緊急性の高い症候は「西洋医学優先」、対象外の症候は「この教材の対象外」と表示します。
- 手がかりと解説の根拠は、次の3種類に分けています。
  - 添付文書：ツムラ医療用漢方製剤の添付文書「効能又は効果」（PMDA掲載）
  - 一般的な使用目標：腹証・古典に基づく慣用的な使い分け
  - 臨床報告：PubMed、Traditional & Kampo Medicine、J-STAGE に掲載された文献
- 添付文書の文言は、要約ツールを通して読み取った部分があります。**最終的には原文（PMDA）で確認してください。**

## 注意

- 学習用の教材です。診療の判断や処方の根拠として使わないでください。
- 症例の内容、誤答の理由、確認の問いは、専門家による確認を経て改訂する前提の版です。
